架构原理

这一板块不讲"怎么用"，讲"怎么运作"。从 init.js 注入运行时开始，到 vino() 返回真实 DOM 结束——中间发生了什么，以及为什么这样设计。

index.html
/static/init.css
/static/init.js
└─ window.jsx = (tag, props, ...childs) => HTMLElement
└─ globalThis._brk_ = { card, icon, opens, _load, ... }
↓ <script>brk.render({ load: ... })</script> ↓
page.mjs
export const page = { vino }
└─ ESM 模块，由 brk._load 动态 import()
└─ 编译产物 ≈ 100% 应用代码
↓ brk._load(meta.load).then(v => ...) ↓
document
document.body.appendChild( v.page.vino({}) )
└─ vino() 返回一个 HTMLElement
└─ 之后的一切更新，由页面自己负责

这个板块适合谁

如果你只是想用 brk 写页面，指南已经足够，不需要读这里。

架构原理是给两类人准备的：一是想贡献代码的人——需要知道运行时如何组织； 二是在选型、需要看到底的人——不想只信文档说"轻量"，想自己判断这套架构是否合理。
