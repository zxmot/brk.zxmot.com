实战配方

指南教你怎么理解，配方给你能直接抄的代码。
每个配方是一个完整场景——从需求到可运行代码，加上取舍说明。 它们不重复指南里的基础，而是把基础组合起来用。

//

每个配方都遵循同样的格式：问题 → 方案 → 完整代码 → 取舍。

代码默认你已经按「快速开始」配好了 init.js 和 esbuild，可以直接复制进项目跑。

01 / MULTI-PAGE SHELL →

多页外壳

带侧边菜单、内容区、tab 切换的后台外壳。覆盖 brk.opens，用 brk._load 挂载子页面。

界面骨架 brk.opens brk._load
02 / KEEP STATE →

切换时保留状态

离开页面时缓存 DOM 到 Map，回来时原样挂回。滚动位置、输入内容、正在跑的动画全部保留。

状态保留 DOM 缓存
